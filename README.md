# Orbit Analytics — Premium Data Dashboard

A compact, dependency-free analytics dashboard concept: dark premium aesthetic,
gradient headline, glassmorphism panels, glow accents and smooth canvas animations.

## Stack

- Vanilla HTML + CSS + JavaScript (no frameworks, no CDN, no build step)
- Canvas 2D chart engine written from scratch (line + donut)
- CSS custom properties for the design tokens, `prefers-reduced-motion` aware

## Files

```
index.html      semantic markup + ARIA labels
css/styles.css  tokens, glass, gradients, responsive layout (360px+)
js/main.js      chart engine, animated counters, ranges, nav, toasts
```

## Features

- Animated KPI counters and sparkline cards
- Trend chart with 7D / 30D / 90D range switching
- Acquisition donut with animated sweep and glow
- Channel performance bars, saved-report cards
- Off-canvas sidebar on mobile, sticky topbar, toast feedback

## Run locally

Open `index.html` in any modern browser — that is the whole setup.
